ILLUMINATED

A page kept the old way

01 The idea

Real gold leaf isn't static — burnished agate-smooth, it throws back whatever light passes over it, so the gilded parts of a manuscript page seem to shift as a candle moves or a reader turns a leaf. ILLUMINATED tries to earn that specific behavior in CSS and SVG: a single generated reference image of an illuminated capital sets the palette, hand-drawn corner ornament frames it, and one animated gradient sweeps across both the headline text and the ornament so they read as gilded by the same light.

02 The craft

  • Headline gold-leaf shine: background-clip:text on a 260%-wide linear gradient, animated via background-position — a loop long enough (5.5s) that it doesn't read as a "scanning" effect
  • Ornament gold-leaf shine: the SVG corner flourishes share the exact same visual language but can't use CSS background-clip on stroked paths, so the shine is a <linearGradient> with an SMIL <animateTransform> sliding the gradient's gradientTransform — same bright-band-over-gold idea, different mechanism because SVG strokes need it
  • The drop cap is invisible until an IntersectionObserver confirms the intro paragraph is on screen, then scales and fades in — a small piece of theater matching how a real illuminator saved the capital for last
  • Blackletter (UnifrakturMaguntia) is used exactly twice — the wordmark and the drop cap — never in body copy, which stays in EB Garamond for actual readability, per the brief's "used sparingly"

What the three passes caught: the build pass found the SVG shine animation kept running even when the CSS text shine was correctly disabled under reduced motion, because SMIL animations aren't touched by the CSS media query — added an explicit JS call to pauseAnimations() on the SVG when reduced motion is detected. The code-review pass flagged body text contrast: --dim at 72% opacity over the lightest parchment corner measured under 4.5:1 for the smaller UI labels — darkened the base ink slightly and reserved full-opacity ink for anything under 1rem. The live-browser pass caught the drop cap's float:left colliding with the paragraph's first line on narrow phones, pushing the "A" awkwardly close to the following word — added a small explicit margin and reduced the drop cap's font size in the mobile breakpoint.

03 Type & color

UnifrakturMaguntia (sparingly) + EB Garamond · parchment #ece0c4, ink #2b1d12, gold #c8952e, oxblood #7a1f2b

04 Reproduce it

  1. Generate one illuminated-manuscript detail image (nano_banana_pro), optimize with sips to keep it well under a megabyte
  2. Frame it in hand-drawn SVG corner flourishes rather than another image — cheaper, sharper at any size, and easy to re-tint
  3. Give text gold shine with an animated background-clip:text gradient; give stroked SVG shapes the equivalent with an animated gradient transform
  4. Gate a large decorative letter behind scroll visibility so it reads as arriving, not just present
  5. Reserve the display/blackletter face for exactly one or two moments; run all reading copy in a genuinely legible serif
