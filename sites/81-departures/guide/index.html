Site 81 · Wave 6 · how it was made

TERMINAL ∞

A full split-flap departures board — every character clatters through the alphabet — for destinations that don't exist

01 The idea

The Solari board, complete: 40+ flaps per row, each stepping through a character drum with a scaleY flip on every step, staggered so updates cascade across the board like the real thing. The destinations are the joke: THE UNCANNY VALLEY is DELAYED, LAST TUESDAY 4PM is BOARDING.

02 How it works

  • Each cell owns a character index into the drum string; setCell steps it one character every ~50ms, retriggering a 70ms scaleY keyframe per step — the clatter is real DOM animation, not video.
  • Rows re-flip on a 6.5s ambient timer; REFLIP cascades the whole board with 160ms row stagger.
  • Status colors follow airport grammar (green/amber/red + a pulsing BOARDING); the clock is real.
  • Reduced motion snaps characters instantly — same board, no clatter.

03 Type & color

  • Oswald for the DEPARTURES header (transit-signage DNA), IBM Plex Mono for the flaps.
  • Board black with amber header and phosphor-green statuses — Zurich Hauptbahnhof at night.

04 The screenshot pass

  • Capture caught the board mid-cascade (statuses half-scrambled — exactly the effect); found one destination exceeding the 26-cell column and shortened it rather than widening the board.

05 Lift this into your site

  • Lift makeLine/setCell/setLine — they're framework-free; a React wrapper is one ref + effect.
  • The flap illusion needs both halves: stepping through intermediate characters and the scaleY blink per step. Skipping either kills it.
  • Keep per-cell stagger ~18ms; simultaneous flips read as a refresh, not a machine.
