Site 88 · Wave 6 · how it was made

LOOM ROOM

A generative loom weaving cloth thread by thread, driven by a real editable weave draft

01 The idea

Textile logic, honored: an 8×8 tie-up grid — the actual notation weavers use — decides at every intersection whether warp passes over weft. The shuttle animates each pick; cloth accumulates below the fell line; editing the draft or choosing twill/herringbone/basket/satin reweaves new fabric.

02 How it works

  • over(r,c) = tie[r%8][c%8] is the entire pattern engine; presets are one-line functions (twill is (r+c)%4<2).
  • Each frame advances the shuttle a few columns, drawing warp-over or weft-over cells; a gold pick fires every 24 rows.
  • Undyed warp hangs faintly below the fell so the loom never looks empty; the beam and shuttle are drawn, not imaged.
  • Reduced motion weaves a full row per frame — the cloth still grows, without the animation.

03 Type & color

  • Crimson Pro's bookish warmth, Space Mono for draft labels.
  • Madder red warp × indigo weft on unbleached ground — natural-dye palette.

04 The screenshot pass

  • Verified herringbone reads correctly (the zigzag is the giveaway) and the shuttle glints; added the hanging-warp fix after the first capture showed bare white below the fell.

05 Lift this into your site

  • The draft system is the star: any 2D boolean function becomes cloth — try noise>0.5 or an image's luminance.
  • Cell size 6–10px reads as fabric; larger reads as pixels.
  • Weave into an offscreen canvas and use it as a live background texture.
