LUMEN

A Type Foundry for Light

01 The idea

A fictional type foundry whose specimens are set in light instead of ink. The hero runs a WebGL aurora shader behind variable-font specimens; scrolling shifts the optical size axis so the typeface itself breathes.

02 The craft

  • Full-screen GLSL fragment shader (layered simplex noise) as the hero backdrop
  • Fraunces variable font animated along its opsz and wght axes on scroll
  • Scroll-linked CSS custom properties (no scroll library, one rAF loop)
  • Specimen cards with mix-blend-mode to let the aurora bleed through the glyphs

03 Type & color

Fraunces (variable, optical sizing) · near-black teal field with aurora gold #f5c96b

04 Reproduce it

  1. Write a fragment shader with 3 octaves of noise, palette-mapped to 3 hues
  2. Expose one uniform for scroll progress; update it in a requestAnimationFrame loop
  3. Set headline font-variation-settings from the same scroll value
  4. Keep UI text on a solid panel so contrast never depends on the shader
