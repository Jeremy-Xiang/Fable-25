Site 85 · Wave 6 · how it was made

LENSA

Draggable glass lenses over a wall of type — real UV displacement refraction with chromatic rims and a moving specular streak

01 The idea

Three glass discs drift over a typographic specimen and bend it honestly: inside each lens, texture UVs are displaced by a lens equation (magnify center, compress rim), RGB splits at the rim, and a specular streak sweeps with time. Grab one and read through it.

02 How it works

  • The type wall renders once to a 2048px canvas → WebGL texture (repainted when fonts finish loading, so the texture uses real Newsreader).
  • Per-fragment: distance to each lens center; inside radius, sample at center + d·(1−k√(1−r²)) — the magnification profile of a plano-convex lens.
  • Chromatic aberration blends in from 55% radius; rim ring + moving spec streak sell the material.
  • Lenses idle on Lissajous drifts and become draggable on pointerdown (hit-tested against radius).

03 Type & color

  • Newsreader at display sizes — serifs bend beautifully; JetBrains Mono for HUD.
  • Ink-navy page, bone type, ice-blue glass accents.

04 The screenshot pass

  • Caught the specimen line colliding with the fixed HUD and moved it right in texture space; verified refraction polarity (center magnifies), rim chroma, and drag hit-testing.

05 Lift this into your site

  • The shader's sampleLens is self-contained — up to N lenses is a uniform array away.
  • Works over any texture: product shots, hero images, code screenshots.
  • Repaint-on-fonts-ready matters for any text-to-texture trick; without it you ship the fallback font.
