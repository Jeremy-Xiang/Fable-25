Site 45 of 50 · how it was made

DUNES

Ridges that shift as you scroll

01 The idea

One Higgsfield-generated hero photograph — warm desert dunes at long-shadow hour — becomes the only texture a WebGL fragment shader ever samples. Four ridge bands are cut from that single image at different scroll speeds and vertical offsets, so scrolling separates one photo into a sense of real depth: the horizon barely moves, the near ridge rushes past underneath it.

02 The craft

  • A single full-screen triangle carries a fragment shader; assets/hero.jpg is loaded as its only texture, with a 1×1 solid-color texture bound first so the scene never flashes untextured
  • Sky gradient (top/mid/bottom stops) is mixed procedurally in the shader; the four sand bands sit on top of it
  • Each band's upper edge is a ridge silhouette from 1D value noise (hash → smoothstep-interpolated noise → two octaves combined), not a straight cut — the noise phase per band is driven by scroll position times that band's own speed multiplier plus a slow time term
  • Where a fragment sits below a band's ridge line, its color is sampled from the same source photo at a texture coordinate that shifts with that band's scroll speed, then blended toward a fixed tint per band for cohesion
  • Scroll progress (0–1 across the page's scrollable height) drives all four bands' phases in a single u_scroll uniform, so the parallax is scroll-locked rather than time-locked
  • A lightweight 2D canvas layered on top adds drifting sand-particle dots, independent of the WebGL layer, gated to zero particles under prefers-reduced-motion
  • If WebGL context creation or shader compilation throws, the scene falls back to a static CSS linear-gradient sky in the same four-stop palette
  • Under reduced motion, the shader still renders — scroll still moves the ridges — but there's no continuous animation loop; a frame is redrawn only on scroll events, and the sand canvas stops spawning particles entirely

03 Type & color

Fraunces (display serif) + Inter (body) + Space Mono (labels) · dusk gradient — cream #f5ead9, ochre #d98f3b, rose #e2645a, violet #4b2b53

04 Reproduce it

  1. Load one photo as a WebGL texture; bind a solid-color placeholder texture first to avoid a flash of black
  2. Build ridge silhouettes from cheap 1D value noise, not a straight horizon — vary frequency and amplitude per band
  3. Drive each band's texture-sample offset and noise phase from a single normalized scroll fraction, at a different speed multiplier per band, back layer slowest
  4. Wrap all WebGL setup in try/catch and swap to a CSS gradient class on failure — never let a shader error blank the page

05 Wing II, asset pipeline

DUNES is Wing II (sites 26–50): rather than Wing I's zero-binary-asset rule, it leans fully on one Higgsfield nano_banana_pro still as the shader's only source material — every band, every ridge, every color you see traces back to that single photograph, resampled four different ways.
