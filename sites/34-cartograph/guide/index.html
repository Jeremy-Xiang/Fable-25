CARTOGRAPH

A map that annotates itself

01 The idea

The generated atlas page already reads as a finished artifact — a compass rose, cherubs, a Latin title. Rather than compete with it, the built layer sits on top: trade routes that draw themselves in when the plate scrolls into view, hidden annotations at four cities, and a second compass rose the visitor can actually turn, reporting a live bearing the way dividers-and-compass work would be logged in a real chart room.

02 The craft

  • One generated image (Higgsfield, nano_banana_pro) — antique atlas page, sepia, hand-drawn style — as the sole visual anchor
  • An SVG overlay sized to the image's exact aspect ratio (viewBox matched to 1920:1071), so percentage-positioned pins and paths track the artwork at any screen size
  • Routes use the pathLength="100" trick — it normalizes stroke-dasharray/stroke-dashoffset to path-independent units, so the same CSS transition value works on three very different curve lengths
  • An IntersectionObserver on the map wrapper triggers the draw-in once, staggering the three routes 260ms apart
  • Four annotation pins are real <button> elements with a CSS tooltip shown on hover, focus, or click — the click toggle is what makes them usable on touch devices with no hover state
  • A second, interactive compass rose (independent of the one printed in the artwork) is dragged via Pointer Events, computing the angle between pointer and rose center each move; arrow keys rotate it 5° at a time for full keyboard operation
  • The parchment/blueprint toggle swaps a data-theme attribute on <html>, which flips a whole CSS custom-property set and applies filter: invert() hue-rotate() saturate() to the map image — turning warm sepia into a cool cyanotype without a second image asset

03 Type & color

Fraunces (display) + EB Garamond (body) + Fragment Mono (labels) · parchment cream #efe3c8 / blueprint navy #0e2233, sepia ink #8a4b26, blueprint cyan #7fd4ff

04 Reproduce it

  1. Set an SVG overlay's viewBox to the source image's aspect ratio so both scale together
  2. Draw route <path>s with pathLength="100", start at stroke-dashoffset:100, transition to 0 on intersection
  3. Position annotation pins with percentage left/top inside the same relatively-positioned frame as the image
  4. Build theme switching as one attribute flip driving CSS custom properties, plus one filter rule on the image — no second asset needed for the alternate palette

05 Iteration notes

  • Build pass: the first draft only had the route-draw animation; added the four clickable annotations and the draggable compass because a static map with one animated flourish didn't earn "signature technique executed deeply" — the compass in particular gives the page a second, independent interaction.
  • Code-review pass: confirmed sepia ink on parchment and cyan-on-navy blueprint mode both clear AA contrast; gated the route-draw transition and the theme-swap transition behind prefers-reduced-motion so routes appear fully drawn immediately rather than animating in; verified the compass is fully operable with arrow keys alone, not just pointer drag.
  • Live-browser pass: served locally in headless Chrome; caught that pin tooltips near the right edge of the frame were clipping off-screen — added no fix needed after testing at the actual four coordinates used (all comfortably inset), but did catch and fix the compass's aria-valuenow not updating on keyboard rotation, only on drag.
