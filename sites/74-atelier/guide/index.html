Site 74 · Wave 5 · how it was made

ATELIER OBSIDIAN

The awards-site studio landing, hand-rolled — preloader, self-drawing monogram, line grid, works reel

01 The idea

Commissioned from a reel flexing alche.studio-style landings — the dark, line-gridded, Japanese-editorial studio site that wins awards. The genre has a recognizable grammar: a percentage preloader, a logo that draws itself, a masked headline reveal, thin structural lines, one acid accent, a horizontally draggable works reel, and a giant email as the only call to action. This page is that grammar reproduced faithfully — with no GSAP, no Lottie, no images. A fictional studio ("Atelier Obsidian") stages it; every "work" thumbnail is a small canvas program.

02 The set pieces

  • Honest preloader: the counter eases toward a ceiling of 88 and only unlocks to 100 when document.fonts.ready actually resolves — so it's a real loading gate with theatrical pacing (minimum 1.1s dwell), not a fake timer. Reduced-motion skips it entirely.
  • Self-drawing monogram: the triangle-and-crossbar mark is three SVG strokes with stroke-dasharray = stroke-dashoffset = path length, animated to zero with staggered delays once body.loaded lands. Same for the two headline rows: spans inside overflow:hidden masks, translated 110% down, released with a 120ms stagger.
  • Line grid: five fixed vertical hairlines at column edges plus two long diagonals rotated from the viewport center — the entire "architecture" of the genre in ~10 lines of JS and one CSS class.
  • Procedural works: each reel card owns a canvas and a tiny draw function (concentric ripples, grain columns, a wireframe moon, sliding bars, smoke béziers) repainted each frame — five distinct "portfolio pieces" with zero image assets.
  • Inertia reel: pointer drag writes velocity; on release the reel coasts with 0.94/frame damping, clamped to content bounds. Horizontal wheel deltas steer it too. The rAF loop sleeps whenever velocity dies.

03 Type & color

  • Instrument Sans for the editorial headline voice, Spline Sans Mono for wayfinding microtext, Zen Kaku Gothic New for the Japanese caption (静寂のなかのデザイン — "design within silence").
  • Near-black #050505, bone ink #e8e6e1, and a single acid accent #d8ff3e used sparingly: hover states, one work highlight, the marquee's Japanese word.

04 The screenshot pass

  • Mobile header collision: at 390px the tracked-out wordmark ran into the nav and INDEX clipped off-screen — caught in the mobile capture, fixed by letting the header wrap with tightened gaps.
  • Drag verification detour: the first headless drag test reported the reel dead — the real cause was the test, not the site: the works section sits below the fold and the synthetic pointer was dragging at off-screen coordinates. Scrolled into view, the reel pulls to −882px and coasts to −944px with inertia. (A defensive try/catch around setPointerCapture was added anyway — synthesized pointers can throw.)
  • Preloader verified headlessly: loader.done and body.loaded both land, and the page renders with zero console errors.

05 Lift this into your site

  • Preloader: copy the loader() IIFE + the #loader block. Swap document.fonts.ready for your real readiness signal (hero image decode(), data fetch). Keep the 88-ceiling trick — counters that glide straight to 100 read as fake because they are.
  • Draw-in logo: any SVG with stroked paths works. Measure each path length (path.getTotalLength() in the console once, hardcode it as --len), set dasharray/dashoffset to it, animate offset to 0.
  • Masked headline: the .rowmask/.row pattern is three CSS rules — the only rule is one mask per visual line, so write your headline as explicit rows.
  • Inertia reel: the whole drag() IIFE is self-contained: needs an overflow-hidden wrap and a width:max-content flex row. Works for any horizontal gallery.
  • Gotchas: pause everything behind prefers-reduced-motion (loader skips, marquee stops, canvases paint once); don't run the preloader on subpages — it's a front-door ritual, not a navigation tax; and keep the accent to under ~5% of the pixels on screen or the whole genre collapses.

06 Reproduce it

  1. Grid first: fixed hairlines + two diagonals. The emptiness is the design.
  2. Preloader gating on a real readiness promise, releasing a body.loaded class.
  3. Hang every entrance (strokes, masked rows) off that one class with staggered delays.
  4. Give each portfolio card a canvas and a 5-line draw function instead of an image.
  5. Drag loop: x += dx while down, x += (vx *= .94) after release, clamp, sleep when still.
