LATHE

Throw a vessel by hand — the profile is the whole vessel

01 The idea

A body of revolution is defined by one 2D curve. LATHE exposes that curve directly: drag anywhere on the clay and you're editing a radial profile — 44 control points from foot to rim — which Three.js's LatheGeometry revolves into a full 3D vessel, live, every frame it changes. Drag sideways to push the wall in or pull it out; drag upward near the rim to pull the whole form taller, the way a real thrower's hands raise the wall.

02 The craft

  • Pointer position maps to profile height by screen-space band (top 14% of viewport = rim, bottom 86% = foot), so shaping works regardless of the mesh's live rotation — a real lathe is radially symmetric, so spin never fights the interaction
  • A Gaussian brush falloff spreads each drag across neighboring profile points, so edits read as smooth clay deformation rather than single-point spikes
  • Dragging upward near the rim increases a global heightScale, stretching the whole revolve taller — a second, coarser control layered on top of the radial one, echoing the actual two-handed motion of throwing
  • Full keyboard path: focus the canvas and use arrow keys — up/down move a focus band along the wall, left/right push and pull the clay at that band, so the piece is operable with no pointer at all
  • Studio lighting is a proper three-point rig (warm spotlight key with shadows, cool point-light fill, warm rim light) plus a low hemisphere fill so the clay reads with real form, not flat color

03 The complexity upgrade

Every drag also writes into a per-point "roughness" value proportional to drag speed. That array is painted into a small canvas texture — banded noise whose contrast scales with roughness — and fed to the clay material as both a bump map and a roughness map. Drag fast and the clay visibly roughens with throwing lines; drag gently and it stays glassy-smooth. It's a detail nobody has to notice to enjoy the piece, but it rewards close attention, which is the point of a deliberate complexity pass.

04 Type & color

Vollkorn + Inconsolata · studio umber #1c140f, wet clay #b0603a, clay highlight #d98a5c, cream #efe3d2

05 Reproduce it

  1. Keep a flat array of profile points (radius + a roughness scalar); rebuild a fresh THREE.LatheGeometry from it whenever it changes and swap it onto the existing mesh
  2. Map pointer Y to a point in that array by screen-space band, not by raycasting against the rotating mesh
  3. Apply drag delta with a Gaussian falloff across nearby points for a smooth "brush," not a hard edit at one index
  4. Accumulate a roughness value per point, repaint it into a canvas each throttle tick, and feed the canvas texture to the material as a bump/roughness map

06 Screenshot pass

The default silhouette was tuned after looking at a real render, not just source: the first pass read as a plain cylinder from the hero camera angle, so the default profile was rebuilt into an actual vase silhouette (narrow foot, full belly, tapered neck, flared lip) so the piece reads as "a vessel" before anyone touches it.
