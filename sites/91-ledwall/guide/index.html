Site 91 · Wave 6 · how it was made

MARQUEE HALL

A stadium LED wall: 7,700 diodes with bloom, scanline refresh, burn-in decay — type a message or spray by hand

01 The idea

The arena screen, simulated at the diode level: a 140×55 grid where each cell is a round LED with radial bloom, per-diode flicker lottery, a rolling scanline band, and dead-diode ghosts in the gaps. Your message rasterizes onto it and scrolls; dragging sprays phosphor by hand that decays like burn-in.

02 How it works

  • Text renders to a tiny offscreen canvas at grid resolution; alpha > .25 becomes the target layer, offset by the scroll position.
  • Each diode lerps brightness toward max(text, spray) at 0.3/frame — that lag is what makes changes bloom instead of blink.
  • Bloom is a per-diode radial gradient; the scanline adds a moving brightness band; spray decays at 0.994/frame.
  • Message input re-rasterizes on Enter; static mode centers instead of scrolling.

03 Type & color

  • Bebas Neue rasterizes into diodes legibly at 46px; IBM Plex Mono for the deck.
  • Amber + signal red on near-black — sodium-lamp stadium palette.

04 The screenshot pass

  • Verified glyph legibility at grid resolution (the whole gamble), bloom overlap, scanline sweep and the input flow; tuned dot pitch until 'YOU LOOK GREAT TONIGHT' fits gracefully.

05 Lift this into your site

  • The three-layer model (target / buffer-with-lag / decay) is the reusable core — it makes any dot-matrix UI feel physical.
  • Radial-gradient bloom per cell is the cost center: cap the grid near 8k cells or precompute sprites.
  • Rasterizing DOM text through an offscreen canvas works for any 'display' effect: flip-dots, nixies, split-flaps.
