SALVO

Thousands of embers, one click

01 The idea

Click anywhere and a burst of hundreds of embers fires from that point — real velocity, gravity, drag, and a warm-to-cool color drift as each particle ages from newborn ember orange to spent violet. The craft flex is scale: a pool of 5,200 GPU instances, recycled continuously, holding 60fps.

02 The craft

  • One THREE.InstancedMesh with a fixed pool of 5,200 quads — no per-particle draw calls, no geometry allocation after startup
  • A custom ShaderMaterial billboards every instance toward the camera by discarding the instance matrix's rotation and re-deriving scale and translation directly in the vertex shader, so particles always face the viewer regardless of camera angle
  • Per-instance color and alpha ride on InstancedBufferAttributes updated once per frame from a typed Float32Array — cheap CPU writes, all blending happens on the GPU via additive blending
  • Physics is plain Euler integration per particle: gravity accel on vy, drag on vx/vz, position += velocity·dt — a ring-buffer allocator recycles the oldest slot in the pool so a rapid click-storm never allocates
  • Hue interpolates per-particle from a randomized ember hue (~14–44°) to a randomized violet/cool hue (~250–290°) over its lifetime, giving each burst natural variation instead of one flat gradient

03 Type & color

Archivo Black + Fragment Mono · near-black #060305, ember orange #ff7a3d, violet #8b5cf6

04 The screenshot pass

The first headless render showed a genuinely empty hero — before any click, the stage was just black with title text, reading as inert rather than an instrument waiting to be played. Added three staggered auto-ignitions on load (skipped entirely under prefers-reduced-motion) so the very first frame already shows the collection's namesake effect in motion, then settles.

05 The complexity upgrade

Beyond the base "click, particles fly" mechanic: a live particle counter in the HUD makes the instancing flex legible rather than just implied, fog (FogExp2) softens distant embers for real depth instead of a flat particle field, and the fragment shader gives each ember a hot inner core plus a softer glow falloff rather than a flat-alpha dot — the difference between "sprite" and "spark."

06 Reproduce it

  1. Create one InstancedMesh(geometry, shaderMaterial, MAX) and add per-instance color/alpha buffer attributes
  2. In the vertex shader, reconstruct scale and translation from instanceMatrix and offset by local position in view space for a camera-facing billboard
  3. Keep a fixed particle pool; recycle via a ring-buffer cursor rather than push/splice
  4. Each frame: integrate gravity + drag, write updated matrices and buffer attributes, flag needsUpdate, render once
