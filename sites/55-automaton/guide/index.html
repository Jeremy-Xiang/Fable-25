A mechanical songbird, wound by hand

01 The idea

Clockwork toy birds are real machines: a wound spring drives a crank, the crank drives linkages, the linkages drive wings and beak in a fixed, physically-determined cycle. The brief for 55 was explicit — no canned CSS keyframe flap, actual linkage math. So the wing motion here is the numerical output of a real four-bar mechanism, and the beak motion is the output of a real cam profile, both solved every frame from the crank angle.

02 The kinematics

  • Four-bar crank-rocker (wings): a short crank (a=18) rotates continuously at pivot O2; a coupler (b=64) connects it to a rocker (c=50) pivoted at O4, with a ground link (d=70) between the two pivots. The rocker's swing angle is found each frame by intersecting two circles — one centered on the crank pin with radius b, one centered on O4 with radius c — the classic RRRR position-analysis problem. Link lengths satisfy the Grashof condition (shortest + longest < sum of the other two, with the ground link adjacent to the crank), which guarantees the crank can spin a full 360° while the rocker oscillates without ever locking up.
  • Radial cam + knife-edge follower (beak): the lower mandible's lift is max(0, sin(2θ))^2.2 — a two-lobe cam profile, so the beak "pecks" twice per crank revolution, like a real pecking-bird automaton.
  • Gear train: the two background gears are geometrically meshed — the small gear's angular speed is the main gear's speed × (R_main/R_small), same as a real spur-gear pair.
  • Winding physics: dragging the key accumulates spring tension; tension drives angular velocity (ω = tension × k); the crank consumes tension as it turns and coasts to a stop, exactly like an unwinding mainspring.

04 The screenshot pass

Rendered headless at desktop and mobile widths. First pass had the wing linkage swinging almost imperceptibly (~4°) because the raw rocker-angle range wasn't renormalized against its own min/max, so most of the arc was wasted off-screen; fixed by mapping the solved rocker angle into a 0–1 fraction across its true swing range, then applying a fixed visual amplitude. Also tightened the proscenium vignette — the first render read a little flat/empty around the bird, so an inset shadow and radial glow were added to focus the eye on the mechanism.

05 The complexity upgrade

An escapement-style tick synthesized in Web Audio, gated to actual gear-tooth crossings: the crank angle is checked each frame against a 14-tooth division, and a click fires only when a new tooth boundary is crossed, with its gain scaled to the current angular velocity — so the ticking genuinely speeds up and slows down with the spring, instead of looping on a timer.

06 Reproduce it

  1. Pick Grashof-valid four-bar lengths (shortest link = crank, ground adjacent to crank)
  2. Solve the rocker point via circle-circle intersection each frame from crank angle θ
  3. Normalize the solved angle into a 0–1 range once at load, then map to visual degrees
  4. Drive a second mechanism (cam or second linkage) off the same θ for secondary motion
