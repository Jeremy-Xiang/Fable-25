Custom cursor · state machine

The cursor reads the page before you do.

One blob, four states. Hover a link, a button, the drag chip or a line of body text below — the cursor morphs its size, shape and blend-mode to telegraph what will happen if you click, drag, or just keep reading.

Body text

This paragraph is plain reading material — no click target, no drag handle. Run your pointer over these lines and the cursor collapses into a thin vertical caret, the same shape a text cursor would take, signalling "this is prose, not an interactive control."

Move back up to a link or a button and watch it expand again. The whole thing is one DOM element (#cursor) whose size, border-radius and blend-mode are rewritten on every mouseover, driven entirely by a data-cursor attribute read off whatever element the pointer is currently over.
