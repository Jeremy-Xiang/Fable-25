Site 80 · Wave 6 · how it was made

ELASTIC

A variable-font editorial where scroll velocity drives weight, softness, and a squash-stretch — with an underdamped spring

01 The idea

Kinetic type that responds to how you scroll, not where: fling the page and every headline gains weight, softens, and stretches; stop and it rings past its rest weight once before settling — a plucked string, not a fade. The typeface itself is the speedometer.

02 How it works

  • Scroll velocity feeds a spring (k=90, damping ratio 0.55 — deliberately underdamped) whose position maps to three channels: wght 340→820, SOFT 0→80, and scaleY 1→1.045.
  • Axes are set as CSS custom properties on :root; every .stretch headline reads them via font-variation-settings, so one write animates the whole page.
  • Fraunces' WONK axis stays at 1 on italics permanently, because a little wonk is good for you.
  • A meter HUD prints velocity/wght/SOFT/stretch live.

03 Type & color

  • Fraunces variable (wght+SOFT+WONK all live), Azeret Mono for meters.
  • Near-black plum with one pink #ff6b9d — editorial, not synthwave.

04 The screenshot pass

  • Verified resting state (wght 340, meter zeros) and layout; the spring dynamics are numbers-verified by the meter (mid-fling weight rises, overshoot on release) in interactive testing.

05 Lift this into your site

  • Copy the spring loop + the CSS variable plumbing; point it at any variable font (check its axes on v-fonts.com).
  • Underdamping is the taste: damping ratio 0.5–0.6 rings once; 1.0 is boring; 0.3 is a diving board.
  • Gate everything behind prefers-reduced-motion — axis pinning is one conditional.
