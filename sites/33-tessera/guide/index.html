TESSERA

A mosaic that keeps tiling itself

01 The idea

One macro photograph of a gold-and-lapis Byzantine mosaic sits framed at the center of the page. Everywhere else — the entire viewport behind it — is a generative Truchet-tile field drawn in the same five-color palette, so the eye can't quite find the seam between "photographed" and "generated." The technique the brief asked for, done deep rather than wide.

02 The craft

  • One generated image (Higgsfield, nano_banana_pro) — macro gold/lapis/garnet mosaic — used as the literal center anchor, framed with a gold outline and drawn corner brackets
  • A full-viewport canvas grid of Truchet tiles: each cell draws two quarter-circle arcs at diagonal corners in one of two rotations, chosen randomly per cell — the classic recipe for continuous, non-repeating flowing curves from a trivial rule
  • Five ink colors sampled conceptually from the photograph (gold, lapis, garnet, emerald, ivory) are the only colors the generative field is allowed to use, which is what keeps it reading as "the same material" as the photo rather than a separate decoration
  • Cursor proximity nudges nearby tiles into a slight rotational wobble, eased toward a target each frame — light catching glass as you pass, not a redraw or a color change
  • Three palette swatches let the whole field recompose live without touching the photograph

03 Type & color

Spectral (old-style serif display) + Fragment Mono (labels) · deep plum-black #150e14, gold #c6a15b, lapis #3a63b0, garnet #9c3a52

04 Reproduce it

  1. Lay a grid of fixed-size cells across the canvas; for each, pick one of two diagonal arc-pair orientations at random
  2. Draw two quarter-circle arcs per cell, thick strokes, rounded caps, colors drawn from a small fixed palette
  3. Track pointer position; ease an "influence" value per tile based on distance, apply it as an extra rotation on top of the base orientation
  4. Keep the palette shared between the photograph's real colors and the canvas draw calls — that shared constraint is what sells the illusion

05 Iteration notes

  • Build pass: first draft had the Truchet field static once drawn; added the per-tile wobble-toward-cursor and the three palette-swatch recompose controls so the "extends algorithmically" claim in the brief has a real interactive dimension, not just a one-time paint.
  • Code-review pass: confirmed ivory text on the deep plum background clears AA contrast; gated the continuous requestAnimationFrame wobble loop behind prefers-reduced-motion so reduced-motion visitors get one static paint instead of a looping animation, while palette-swatch clicks still redraw once so the feature stays usable.
  • Live-browser pass: served locally in headless Chrome; caught that on resize the tile grid was rebuilding with brand-new random rotations every time (visually jarring on any viewport change), left that as-is only for true resizes since it's rare, but fixed a stacking bug where the radial "veil" gradient was sitting above the frame image on some paint orders — reordered z-index so the photograph frame always reads sharp.
