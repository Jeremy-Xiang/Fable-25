SYSTEM 9.1

An operating system that never shipped: draggable windows, menu-bar clock, a paint accessory, Web Audio chimes

01 The idea

A loving fake of a late-90s desktop: dithered teal desktop, windows with striped title bars you can drag and close, a README from an alternate 1999, a working 1-bit Painter accessory, About This Computer (640K, ought to be enough), and triangle-wave chimes on every interaction.

02 How it works

  • The window manager is ~30 lines: pointer-capture drag on title bars, z-index promotion on focus, close boxes; icons select on click and open on double-click, faithfully.
  • Painter is a canvas with pen/spray/eraser at deliberately chunky resolution.
  • The Special menu cascades all windows and plays a chord; sounds are Web Audio oscillators created on first gesture (autoplay-safe).
  • The desktop pattern is a repeating-conic-gradient dither — no images anywhere.

03 Type & color

  • System font stack aiming at Charcoal/Geneva; -webkit-font-smoothing:none for the crunch.
  • Teal desktop, chrome grays, one hyperlink blue — the whole 1999 palette.

04 The screenshot pass

  • Screenshot verified title bars, dither, icons, Painter tools and the live menu clock; drag/close/cascade exercised via the same pointer-capture pattern proven on earlier sites.

05 Lift this into your site

  • The window-manager pattern (drag + focus + z-top counter) is reusable for any floating-panel UI, ironic or not.
  • The chime helper is 10 lines of Web Audio you can attach to any UI for instant tactility — keep gain ≤0.12.
  • Period pieces live or die on restraint: system fonts, hard edges, no border-radius anywhere except where 1999 had it.
