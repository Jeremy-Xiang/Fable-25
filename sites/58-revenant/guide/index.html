Site 58 of 62 · how it was made

REVENANT

A formation of thousands of points, briefly a person

01 The idea

No mesh, no skeleton — just 4,200 independent points that know two things: where they are, and where they're supposed to be. A figure only exists because enough of them agree to stand still at once. The brief called for the "ghost" to read through point density and motion rather than geometry, so there is no outline drawn anywhere; the silhouette is an emergent effect of thousands of dots converging.

02 How the figure is built

  • Procedural silhouette function: bodyHalfWidth(t) returns the figure's half-width at normalized height t (0=feet, 1=head-top) — piecewise sine/linear segments for legs, hips, torso, neck and head, plus a separate armReach(t) lobe for the torso band.
  • Rejection sampling: points are proposed at random (t, x) and accepted only if x falls inside the silhouette's width at that height — the standard way to sample uniformly inside an arbitrary implicit region without ever rasterizing it.
  • Hand-rolled value noise (smoothstep-interpolated hash lattice, no library) drives per-particle jitter while holding and drift while dispersed, so the motion reads as organic rather than random-per-frame static.

03 The cycle

A simple three-state machine — hold → disperse → recoalesce → hold — runs on a timer and can be interrupted early by a click or the "Disperse now" button. Hold applies a strong spring pull to each point's target with light noise jitter; disperse releases the pull entirely and lets accumulated velocity plus noise carry points outward like fog; recoalesce ramps the pull back in gradually so the reformation looks like a gathering, not a snap.

04 Type & color

Cardo (italic display) + Fragment Mono · near-black #050709, cold desaturated point color #7fa3ad, single warm point-light accent #ffb37a that follows the cursor

05 The screenshot pass

The first headless render landed mid-recoalesce with points still scattered, so the screenshot showed a formless haze with no discernible figure — a bad first impression for a piece whose entire premise is "briefly a person." Changed particles to spawn already in formation and open directly in the hold state, so a visitor (and the screenshot harness) sees a legible figure immediately, with the disperse/recoalesce cycle still running on its normal timer afterward. Also widened the figure and added a sparse ambient dust field either side of it — the first render's narrow column left too much empty black either side and read as generic.

06 The complexity upgrade

A warm point-light accent that follows the cursor: any particle within its radius shifts from cold desaturated blue-grey toward warm amber and brightens, as if a lantern were passing through the crowd of points — a physically-inspired lighting gesture layered on top of a system that otherwise has no concept of light.

07 Reproduce it

  1. Write an implicit 2D silhouette function (width as a function of height)
  2. Rejection-sample points inside it until you have as many as you need
  3. Give every point a target (the sample) and a live position; spring one toward the other
  4. Drive the spring strength itself from a state machine, not the noise
