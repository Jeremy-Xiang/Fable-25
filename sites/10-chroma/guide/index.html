CHROMA∞

A Y2K fever dream

01 The idea

A Y2K/vaporwave artifact: chrome gradient text, a rotating CSS-3D holographic cube, cursor sparkle trail, and a fake OS window that 'crashes' charmingly. Nostalgia executed with modern CSS discipline.

02 The craft

  • Chrome text via layered background-clip gradients + tight text-shadows
  • CSS 3D holo-cube with conic-gradient faces, rotating on two axes
  • Canvas cursor trail with additive blending and decay
  • A draggable fake window (pointer events) with era-correct chrome

03 Type & color

Unbounded + pixel accents · chrome, hot magenta #ff5ad1, cyber lilac

04 Reproduce it

  1. Build chrome type from a 5-stop vertical gradient, clip to text
  2. Give the cube conic-gradient faces; rotate with a paused-on-hover animation
  3. Spawn trail particles on pointermove, fade them in a rAF loop
  4. Keep the body font readable — the nostalgia lives in the decorations
