Curveloop

A curved text loop that never shows a seam — staged as a spinning badge

01 The idea

React Bits' "Curved Loop" is one of the most-lifted components in modern portfolio sites — a strip of text bent around a path, drifting forever, reacting to a drag. Most hand versions either leave a visible gap where the repeated string doesn't quite tile, or the tiling breaks the moment you change the radius. CURVELOOP fixes both: the string is measured and re-tiled every time the radius changes, then force-fit to the exact circumference so the loop closes cleanly at any size. It's staged here as an "open for work" seal badge sitting next to a portfolio name card, the way you'd actually deploy it.

02 How the effect works

  • The path: a single SVG <path> built from two 180° arc commands — M cx-r,cy A r,r 0 1,1 cx+r,cy A r,r 0 1,1 cx-r,cy — is the only way to describe a full circle in one d string, since a single arc command can't close on itself.
  • Seamless tiling: the label unit "OPEN FOR WORK ✦ 2026 ✦ " is measured with CanvasRenderingContext2D.measureText() at the exact font/weight/size used on-screen. repeats = round(circumference / unitWidth) gives a whole number of copies that roughly fill the ring.
  • The seam-killer: the whole <text> element then gets textLength = circumference with lengthAdjust="spacing". SVG stretches or compresses inter-glyph spacing (not the glyphs themselves) until the text's total advance along the path is exactly the circle's circumference — so the last character's end lands exactly where the first character's start began. That's what makes the loop read as infinite rather than a strip with a visible joint.
  • Rotation: one angle accumulator (degrees) drives a transform="rotate(angle, 150, 150)" on the wrapping <g>, reapplied every animation frame — not a CSS @keyframes spin, so it can be pushed by drag or scroll mid-animation without restarting.
  • Drag & momentum: pointer angle is computed each move via atan2(y-cy, x-cx); the frame-to-frame delta becomes both the rotation increment and the instantaneous velocity (deg/s). On release, that velocity is kept as spinVel and eased back toward the autoplay target every frame with spinVel += (target - spinVel) · min(1, dt·2.2) — an exponential decay, not a spring library.
  • Scroll reactivity: a passive scroll listener converts ΔscrollY/Δt into a small nudge added to spinVel (clamped ±260°/s), so flicking past the badge visibly kicks its spin.

04 The screenshot pass

The first headless render at the default radius (110) looked fine, but the whole point of shipping a "curve radius" slider is that people will drag it to its extremes — so before signing off, a small puppeteer script drove the actual page, set #radius to its min (65), mid (90) and max (130) values, and both logged the resulting textLength / rawWidth stretch factor and screenshotted the badge at each step. At radius = 65 the stretch factor came out to 0.484 — the code's Math.max(4, …) floor was force-fitting 4 repeats of the label into a circumference that only naturally fit 2, so lengthAdjust="spacing" had to compress inter-glyph spacing to under half its natural width. The screenshot confirmed it visually: the ring text collapsed into an illegible overlapping blur, not readable text. Fix: lowered the hard floor from Math.max(4, …) to Math.max(2, …) so the repeat count tracks what the measured circumference actually supports instead of overriding it. Re-testing the same three radii afterward gave stretch factors of 0.97 / 0.89 / 0.97 — all close to 1:1, no visible overlap — and as a side effect the default view now shows a slightly roomier 3 repeats instead of a forced, faintly-compressed 4.

05 Lift this into your site

To reuse this in another project, copy these pieces as a unit:

  • Markup: the #badgeWrap > svg#loop subtree — defs>path#circlePath, circle#ringGuide, g#ring>text#loopText>textPath#loopTextPath, and the static g#center. The SVG expects a fixed square viewBox (here 0 0 300 300) — keep CX/CY in the script matched to its center.
  • Functions: circlePathD(r), rebuildRing(r) (measure + retile + set textLength), pointerAngle(e), applyRotation(), and the loop(now) rAF tick that eases spinVel toward baseSpeed.
  • Constants to tweak: BASE_UNIT (the repeating label string), the font string inside rebuildRing (must match the on-screen font-family/weight/size or the measured width will be wrong and the loop will visibly gap or overlap), baseSpeed (deg/s), and the decay rate 2.2 in the easing line (higher = snappier settle after a drag).
  • Gotchas: set touch-action:none on the SVG/wrapper (already done) or touch-drag will scroll the page instead of spinning the badge. Respect prefers-reduced-motion by setting the autoplay target to 0 instead of disabling the script entirely — the badge should stay drag- and keyboard-operable, it just shouldn't idle-spin forever on its own. If you change the radius dynamically, always re-run rebuildRing() — the textLength value is radius-dependent and stale values reintroduce the seam. If you make the min radius smaller than roughly one label-unit's width, don't hard-floor the repeat count (see 04) — let it track the measured circumference or the glyphs will overlap into a blur.

06 Reproduce it

  1. Draw a full-circle <path> from two semicircular arc commands; give it an id for textPath to reference
  2. Measure your repeating label string's pixel width at the exact on-screen font via canvas.measureText()
  3. Tile the string round(circumference / unitWidth) times into the <textPath>
  4. Force an exact fit with textLength=circumference and lengthAdjust="spacing" on the parent <text> — this is what removes the seam
  5. Rotate a wrapping <g> via a JS-driven transform="rotate(angle,cx,cy)" each frame, feeding it autoplay speed, drag delta, and (optionally) scroll velocity into one shared velocity variable
