CENSER

Smoke remembers a shape, then lets it go

01 The idea

A few hundred smoke particles drift through a curl-noise flow field, wandering like real incense smoke. On a slow cycle, they abandon free drift, seek a set of hand-authored calligraphic stroke paths, hold that near-legible glyph silhouette for a moment, then release back into the flow field and disperse. Touching or dragging near the smoke gently pulls it, like disturbing real vapor.

02 The craft

  • Curl noise from scratch: a value-noise field (hashed lattice + smoothstep interpolation) is sampled at four offset points to build a numerical gradient, then rotated 90° — the standard trick for turning a scalar noise field into a divergence-free (non-clumping) velocity field
  • A four-phase cycle (drift → coalesce → hold → disperse) drives a seekT target per particle; only during coalesce/hold does an attraction force toward its assigned glyph-stroke point activate, so the same curl field governs motion throughout — the glyph is a temporary attractor, not a swap to a different system
  • Glyph "strokes" are hand-authored polylines (abstract brush gestures, not real script) sampled into evenly spaced points, one assigned per particle so the coalesced shape has consistent density
  • Canvas trail effect via a low-alpha fill each frame instead of a full clear, giving the smoke natural motion blur without a blur filter
  • Pointer/touch proximity applies a small radial force so the visitor can visibly disturb the smoke without taking over the simulation

03 Type & color

Cormorant + Fragment Mono · warm incense black #0e0c09, muted amber #c99a5b, smoke grey #a89e93

04 The screenshot pass

Early renders during the "drift" phase looked correct but sparse and directionless — a fair critique of a screenshot caught mid-cycle. Tuned the coalesce/hold timing so the cycle reaches a visibly-forming glyph reasonably early, and increased per-particle glow slightly during coalesce/hold so the shape reads at a glance even in a static frame, not only when watched continuously.

05 The complexity upgrade

Beyond plain curl-noise drift: the four-phase state machine (drift/coalesce/hold/disperse) makes the piece contemplative rather than purely decorative — it has a narrative arc that repeats — and each particle's brightness pulses on its own phase offset so the smoke has fine-grained flicker instead of uniform opacity, closer to how real backlit smoke catches light unevenly.

06 Reproduce it

  1. Build 2D value noise (hash lattice corners, smoothstep-interpolate)
  2. Curl: sample noise at (x,y±ε) and (x±ε,y), take the perpendicular of the finite-difference gradient
  3. Advect particles by integrating that curl vector as acceleration each frame, with damping
  4. Add a state machine that blends in a secondary attraction force toward target points during specific phases only
