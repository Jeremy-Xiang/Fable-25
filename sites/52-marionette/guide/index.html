MARIONETTE

Every string obeys gravity

01 The idea

A wooden puppet hangs from a control bar by six strings. Grab any joint — head, hand, or knee — and drag it; the whole body responds through real physics, not a canned swing animation. Let go and gravity, damping, and stick constraints settle it back into a hanging pose.

02 The craft

  • Hand-rolled verlet integration: each joint is a point tracking its current and previous position; velocity is implicit as current − previous, so no explicit velocity vector is stored or integrated separately
  • Two tiers of "sticks" (distance constraints): stiff, near-rigid ones form the puppet's limbs; soft, lower-stiffness ones are the six visible control strings, solved with weaker correction so they behave springier than bone
  • Constraint relaxation runs 6 iterations per frame (Jakobsen-style position-based dynamics) — the standard trick that makes verlet cloth/rope solvers stable without a stiffness matrix
  • The dragged point is excluded from gravity integration and from constraint correction on its own side, so it acts as a hard pin the rest of the system reacts to
  • The control bar sways gently on a sine drift so the puppet is never fully at rest, even before the visitor touches it

03 Type & color

Fraunces + Fragment Mono · stage black #0d0804, warm amber signal #e8a355, cream #f2e6d0

04 The screenshot pass

Headless render caught two things: the puppet's default rest pose initially drifted too close to the bottom edge on short mobile viewports, clipping the feet against the stage floor line, so the vertical scale now derives from min(width,height)/9 instead of a fixed pixel scale. It also showed the reset button crowding the footer text on narrow screens — shrank and repositioned both in the mobile breakpoint so they read as separate control layers.

05 The complexity upgrade

Beyond the base drag-a-joint mechanic: drifting dust motes cross the spotlight beam at different depths and speeds, a two-tier stiffness system gives strings and limbs visibly different physical character (springy vs. rigid) rather than treating every constraint the same, and the head joint gets a small procedural face (brow line, two eyes) instead of a bare circle — the kind of detail that makes it read as a puppet rather than a physics diagram.

06 Reproduce it

  1. Represent each joint as {x,y,px,py}; integrate by reflecting position across itself plus gravity, no velocity field
  2. Define sticks as {a,b,restLength} pairs; each relaxation pass nudges both ends toward the rest length
  3. Pin the control-bar points and the actively dragged point; skip gravity/constraint correction for pinned points
  4. Run several relaxation iterations per frame for stability, then draw sticks as line segments between joints
