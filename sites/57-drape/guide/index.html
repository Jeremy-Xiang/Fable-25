DRAPE

Cloth that answers to gravity — no physics library

01 The idea

Fabric web demos usually fake drape with a CSS transform or a pre-baked animation. DRAPE actually simulates it: a grid of point masses connected by springs, integrated frame by frame under gravity, wind and collision — the folds you see are the numerical output of that system settling, not an artist's keyframe.

02 The simulation

  • Grid: 26×24 point masses, top row pinned to an implied rod.
  • Three spring families: structural springs (direct grid neighbors) hold the fabric's overall size; shear springs (diagonal neighbors) resist skewing so the cloth doesn't collapse into a blob; bend springs (skip-one neighbors) resist sharp creasing so folds look like cloth, not paper.
  • Hooke's law + damping: each spring's force is k·(currentLength − restLength) along its axis, plus a velocity-projected damping term so the mesh doesn't ring forever.
  • Integration: semi-implicit Euler with sub-stepping (two half-steps per frame) for stability at interactive spring stiffness.
  • Collision: a simple sphere stands in for "an implied form" — any point that ends up inside it is projected back to its surface each frame, so the cloth visibly drapes over a rounded shape instead of passing through it.
  • Wind: cursor velocity near the mesh applies a local, falloff-weighted force; a "Gust" button and an ambient sine drift add motion without a mouse.

03 Type & color

Vollkorn (italic display) + Fragment Mono · parchment #efe7dc, cloth gradient #c9b8a0→#665644, single thread accent #a63d2f

04 The screenshot pass

First headless render showed the mesh sagging into a flat, undifferentiated sheet with almost no visible fold shading — the fake-normal shading term was too subtle. Increased its contrast and added a directional light bias so triangle brightness varies more with local fold angle, which makes the drape read as three-dimensional fabric instead of a flat gray panel. Also caught that the wind slider's default value produced almost no visible ambient motion on first paint; raised the default so the piece feels alive on load.

05 The complexity upgrade

A stitched hem: the bottom edge of the mesh is traced every frame as a dashed accent-colored line following the actual simulated point positions — so the "stitching" itself flutters and folds with the cloth in real time rather than sitting on top as a static decoration.

06 Reproduce it

  1. Build a point grid; pin the row that should hang from something fixed
  2. Connect structural + shear + bend springs, record each spring's rest length
  3. Each frame: accumulate gravity + spring (Hooke + damping) + wind forces per point
  4. Integrate with semi-implicit Euler, sub-stepping for stability
  5. Resolve collisions against any implied solid form last, before rendering
