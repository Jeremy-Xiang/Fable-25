PHOSPHOR/1979

A terminal that remembers

01 The idea

A CRT terminal from 1979 that boots, types to you, and takes commands (help, about, guide, index). Scanlines, phosphor bloom and barrel curvature are layered CSS; the cursor blinks at the historically correct 530ms.

02 The craft

  • Typewriter engine with variable per-character delay and mistake/backspace moments
  • CRT stack: scanline gradient, vignette, animated flicker, glow text-shadow
  • A real command parser — the page is navigable entirely by keyboard
  • VT323 with green phosphor #33ff66 on true black

03 Type & color

VT323 · phosphor green on black, amber for warnings

04 Reproduce it

  1. Queue lines as [text, delay] tuples; type them with jittered timeouts
  2. Layer scanlines with a 4px repeating-linear-gradient at low alpha
  3. Add glow with two text-shadows, never blur the font itself
  4. Parse input on Enter; unknown commands should answer in character
