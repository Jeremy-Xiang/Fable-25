How the growth is seeded

On load, the page draws the hero photograph into a hidden canvas and scans it for pixels that are bright and green-shifted — the glowing thread and mushroom-cap pixels, not the dark soil around them. A spread of the strongest matches becomes the starting points for a recursive branching system, mapped back into on-screen position using the same math the browser uses to crop the image under object-fit:cover.

From each seed, a growth tip steps forward every frame with a small random heading change, occasionally splitting into two tips at a shallower angle and a little less width — the same simple rule set behind L-systems and real fungal growth alike. Depth and life both run out eventually, so the network fills in and settles rather than growing forever.
