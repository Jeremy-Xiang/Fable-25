FACET

One gem, cut by math

01 The idea

FACET is Wing II's second real-3D showcase and its one site with zero generated imagery — every pixel is computed at render time. A zero-subdivision icosahedron reads as a cut gem because it's flat-shaded: the same geometry smoothed would look like a soccer ball, not a jewel. A refractive material samples a procedurally shaded environment sphere instead of a photo, and a single spotlight orbits the gem cycling through five jewel tones so each facet flashes a different color as it catches the light.

02 The craft

  • IcosahedronGeometry(1.9, 0) — detail level 0 keeps every triangle a distinct flat facet; flatShading:true on the material stops Three.js from smoothing normals across them
  • MeshPhysicalMaterial with transmission, ior:2.4 and clearcoat approximates glass/gem optics without a full path tracer
  • The environment map is a hand-written fragment shader painted onto a CubeCamera render target — five jewel-tone bands blended around a sphere, so the "reflections" the gem shows are procedural, not a loaded HDRI
  • A single SpotLight orbits on an ellipse, its color stepped through five hex values once per lap — a facet nav indicator at the bottom mirrors which jewel tone is currently active
  • Pointer drag adds rotation velocity that decays back to a slow default spin — direct manipulation, not just autorotation
  • WebGL is feature-detected before the renderer is even constructed; failing that (or if WebGLRenderer throws), a CSS conic-gradient gem with a hue-rotate animation stands in, with a visible notice explaining why

What the three passes caught: the build pass found the first environment shader produced banding harsh enough to look like a bug rather than a gem facet — softened the band transitions with mix() and cross-faded five colors instead of a hard three-color split. The code-review pass caught the spotlight's color-index calculation running every frame with a modulo against a floating-point orbit angle, occasionally flickering between two indices at the boundary — added a rounding step and only updated the facet-nav dots on actual index change. The live-browser pass found the CSS fallback gem was invisible against the black background at low screen brightness because brightness(.85) was too aggressive on the conic-gradient — raised it and confirmed the WebGL-unavailable notice actually renders (tested by disabling WebGL via browser flags).

04 Reproduce it

  1. Feature-detect WebGL before constructing a renderer; write the CSS fallback first so it's never an afterthought
  2. Build a low-poly gem from an IcosahedronGeometry at detail 0 with flatShading:true
  3. Render a small procedural gradient sphere into a WebGLCubeRenderTarget and feed it to the gem material's envMap for reflections with no photo asset
  4. Orbit one colored spotlight around the subject on a slow ellipse, stepping its color through a fixed jewel-tone array
  5. Let pointer drag set rotation velocity rather than absolute rotation, so releasing the drag keeps a natural decay spin
