Site 31 of 50 · how it was made · Wing II

RISO CLUB

Two inks, one plate at a time

01 The idea

Wing II's brief for this slot was a risograph zine: flat, grainy, slightly misregistered prints, the kind that come off a duplicator drum one ink at a time. Rather than fake that look once and freeze it, the site turns the duotone recipe into a live control — visitors swap the ink pair and watch the exact same illustration get replated in a different two-color story, with the halftone screen and registration jitter riding along.

02 The craft

  • One generated illustration (Higgsfield, nano_banana_pro) — a flat riso-style plant poster, already close to duotone, used as the base plate
  • filter: grayscale(1) contrast(1.25) strips the source to tonal values only, so any ink pair reads correctly regardless of the image's original hues
  • A second layer sits on top with mix-blend-mode: color and a two-stop linear-gradient background — swapping the gradient's two colors via CSS custom properties (--inkA/--inkB) re-tints the whole print instantly, no image reprocessing
  • Halftone: a repeating radial-gradient dot pattern at a 4px grid, multiply-blended, standing in for the print screen
  • Grain: an inline SVG feTurbulence filter data-URI, overlaid at low opacity in overlay blend mode for paper noise without a texture asset
  • Registration wobble: on hover/focus, the base layer and the color-wash layer each get an independent steps() keyframe animation nudging them 1–2px apart, mimicking hand-fed plates that never perfectly align

03 Type & color

Anton (display) + Space Mono (body/labels) · cream stock #f2ead6, ink navy #191a3d, three swappable ink pairs (fluoro pink/navy, flame/blue, kelly green/red)

04 Reproduce it

  1. Grayscale + contrast-boost the source image so only luminance remains
  2. Stack a blend-mode layer above it; its background gradient supplies the two ink colors
  3. Expose the two colors as CSS custom properties so a button click can retint live
  4. Layer a small-tile radial-gradient halftone and an SVG-noise grain on top, both blended, both non-interactive (pointer-events:none)
  5. On hover, animate the base and wash layers on separate, slightly offset step-timings for the misregistration effect

05 Iteration notes

  • Build pass: first draft only had one fixed ink pair; added the three-swatch ink selector so the duotone technique is demonstrably live, not a single baked screenshot, and added the back-catalog strip so the page has real content depth beyond one hero image.
  • Code-review pass: checked contrast of navy text on cream (passes AA comfortably), made the print card a focusable <figure tabindex> so keyboard users can trigger the same wobble state as hover, and gated all animation behind prefers-reduced-motion so the wobble and card-lift transitions are removed entirely rather than just slowed.
  • Live-browser pass: served locally and checked in headless Chrome — caught that the halftone dot layer was rendering slightly too dark at full opacity and muddying the pink ink pass, dropped it from .5 to .35 opacity; confirmed the ink-swatch buttons are reachable and operable by keyboard alone.
