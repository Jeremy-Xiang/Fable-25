Site 50 of 50 · how it was made

ECLIPSE

Two bodies, one line — the collection's closing piece

01 The idea

ECLIPSE stages the geometry of totality as something you can nudge: a real 3D moon sits directly between the viewer and a light source, in front of a shimmering solar corona. Drag the moon — or tab to it and press the arrow keys — and it slides off the line, un-eclipsing the light at the rim it uncovers, then eases itself back into alignment when you let go. It's the finale by design: the last of fifty sites, and the only one built to combine all three of Wing II's signature techniques — a generated hero image, a generated motion loop, and genuine Three.js 3D — inside a single frame.

02 The craft

  • A fixed backdrop layer holds a looping corona video (assets/hero.mp4) with its poster frame set to a still generated image (assets/hero.jpg), so something correct renders even before script runs
  • A Three.js scene sits on top: a THREE.Sprite with a radial-gradient canvas texture and additive blending stands in for the fixed light source, and a real SphereGeometry mesh — the moon — occludes it, lit only at its silhouette by a custom Fresnel rim ShaderMaterial tuned to the corona's gold
  • Interaction is dual-input: pointer drag and keyboard arrow keys both feed the same offset target, which the render loop eases the moon toward with simple lerp damping, then springs back to center after a short delay once input stops
  • prefers-reduced-motion is honored at three separate points — the corona video is never fetched or played (the poster stays static), the shader's shimmer term (uFlicker) is zeroed so the rim holds still, and the render loop itself switches from continuous requestAnimationFrame to single on-demand repaints after each discrete input
  • A WebGL capability check wraps the entire Three.js setup in try/catch; if it fails for any reason, the canvas is hidden and a pure-CSS fallback (a radial-gradient corona with a keyframe flare, itself disabled under reduced motion) takes over so the piece still reads as an eclipse with zero WebGL

03 Type & color

Bodoni Moda + Fira Code · near-black #040404, off-white #f5f3ee, gold #d9b26a, gold-bright #f2d38a, dim #a49a86

04 Reproduce it

  1. Layer three fixed full-viewport elements by z-index: video/image backdrop at the bottom, a WebGL canvas above it, page content above that
  2. Build the light as an additive-blended sprite fixed at scene center; build the occluder as a sphere whose Fresnel-shaded rim color matches the light
  3. Drive the sphere's x/y offset from both pointer and keyboard events into one shared target value, lerp toward it every frame, and schedule a spring-to-zero after input goes idle
  4. Gate all motion — video autoplay, shader shimmer, continuous rendering — behind a single matchMedia('(prefers-reduced-motion: reduce)') check, and provide a no-WebGL CSS fallback so the concept survives without a GPU

05 Closing the two wings

ECLIPSE is the last of fifty, so this guide closes the story both wings were telling.

Wing I — sites 1–25

A deliberate zero-binary-asset flex: every visual was procedural — hand-written shaders, SVG, canvas drawing, Web Audio synthesis — with no generated or photographed imagery anywhere. That discipline and its techniques are documented in full in the master guide.

Wing II — sites 26–50

The counterpart the master guide named as the alternative path: the generated-imagery pipeline. Higgsfield nano_banana_pro stills served as key hero assets across most of the wing; Kling video loops were used where motion earned its cost (32-oscilloscope, 42-inkwash, and this site's corona); and real Three.js 3D formed a third axis (35-orrery, 38-facet, 48-murano) — with ECLIPSE closing it by combining all three at once: 3D occlusion, a generated and animated backdrop, and motion design, in one scene.
